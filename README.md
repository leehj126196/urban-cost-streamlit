# 도시계획시설 개략사업비 산정기

구역계를 업로드하면 편입필지를 자동으로 찾고 다음 산식으로 개략사업비를 계산하는 Streamlit 앱입니다.

- 토지보상비 = Σ(편입면적 × 개별공시지가 × 토지 표준보상비 배율)
- 건축물보상비 = Σ(연면적 × 기준단가 × 잔가율)
- 공사비 = 구역계 면적 × 기반시설별 단위당 표준조성비
- 총 개략사업비 = 토지보상비 + 건축물보상비 + 공사비

## 공사비 기준
사용자가 제공한 국토교통부 고시 제2025-398호 기준을 적용합니다.

- 도로: 173,000원/㎡
- 공원: 105,000원/㎡
- 녹지: 87,000원/㎡
- 적용기간: 2025.06.10 ~ 2026.06.09

## 지원 파일
- SHP 구성파일 ZIP
- SHP
- GeoJSON / JSON
- GPKG
- DXF

DXF처럼 좌표계 정보가 없는 파일은 앱 사이드바에서 원본 EPSG 번호를 직접 입력합니다. 변환 위치가 대한민국 범위를 벗어나면 좌표계 오류 경고를 표시합니다.

## Streamlit Secrets
Streamlit Community Cloud의 App settings > Secrets에 아래 항목을 등록합니다.

```toml
VWORLD_API_KEY = "..."
VWORLD_DOMAIN = ""
BUILDING_HUB_API_KEY = "..."
LEGAL_DONG_API_KEY = "..."
```

실제 키는 GitHub 저장소에 업로드하지 않습니다.
